# Brand fonts (user supplied)

Keep `Dirooz.ttf` and `Miremad.ttf` here in your local project.
The build copies available originals into `public/fonts/` automatically.
The source distribution intentionally does **not** redistribute font binaries.
A checkout without the binaries still builds, using CSS fallback fonts.
For a GitHub/Cloudflare deployment with the exact brand typography, add your
licensed font files to this directory in your own repository.
